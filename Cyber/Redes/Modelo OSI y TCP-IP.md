
## OSI (7-capas)
| Nº  | Capa                | Función principal            | Ejemplos        |
| --- | ------------------- | ---------------------------- | --------------- |
| 7   | **Aplicación**      | Interacción con el usuario   | HTTP, FTP, SMTP |
| 6   | **Presentación**    | Formato, cifrado, compresión | SSL/TLS         |
| 5   | **Sesión**          | Mantiene y cierra sesiones   | NetBIOS         |
| 4   | **Transporte**      | Control de flujo y puertos   | TCP, UDP        |
| 3   | **Red**             | Direccionamiento y routing   | IP, ICMP        |
| 2   | **Enlace de datos** | MAC, tramas, acceso al medio | Ethernet, ARP   |
| 1   | **Física**          | Señales, cables, bits        | UTP, fibra      |

## TCP/IP
| Capa            | Función                        | Ejemplos        |
| --------------- | ------------------------------ | --------------- |

| Internet        | Direccionamiento y routing     | IP, ICMP        |
| Transporte      | Comunicación extremo a extremo | TCP, UDP        |
| Aplicación      | Servicios al usuario           | HTTP, DNS, FTP  |
